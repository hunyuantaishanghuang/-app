# 老年人健康管理体检阳性体征筛查系统 (完全离线使用指南)

本系统专为基层卫生院、社区卫生服务中心设计，用于从公共卫生管理平台导出的多表或花名册中，**自动筛查 11 项阳性体征，并导出【姓名加异常项清单】**。

---

## 🌟 方式一：双击直接离线运行（最简单，无需任何安装环境）

在解压后的项目根目录下，直接找到：
👉 **`双击直接离线使用_免安装版.html`** （在 `public/offline.html` 中也有备份）

- **完全零依赖**：无论电脑上有没有 Python、Node.js，都不需要安装任何软件。
- **完全零网络**：拔掉网线、在物理隔离的内网电脑上双击即可在浏览器（Edge / Chrome / 360 等）秒开运行。
- **多表身份证自动关联**：把公卫系统导出的 `超声所见.xlsx`、`生化检查.xlsx`、`血常规.xlsx`、`人员名单.xlsx` **直接拖入页面**，系统会自动以【身份证】作为主键进行全外连接合并。
- **一键导出**：点击顶部的「导出【姓名+异常项】清单」，自动生成排版好的 Excel。

---

## 🌟 方式二：在有 Python 环境的电脑上运行命令行批量脚本

在终端中进入本项目目录，执行：

```bash
# 1. 安装基础依赖（仅需执行一次）
pip install pandas openpyxl

# 2. 运行筛查（支持传入单个表，或同时传入多个检查分表）
python screen_elderly_health.py 人员名单.xlsx 生化.xlsx 超声所见.xlsx 血常规.xlsx
```

运行完毕后，脚本会在当前目录下自动输出：
`老年人阳性体征_姓名与异常项清单.xlsx`

---

## 🌟 方式三：本地开发服务器方式启动（Node.js / Vite 完整模式）

如果您电脑上有 Node.js 环境，想在本地运行完整的前端服务：

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务 (离线可用)
npm run dev
```

启动后在浏览器打开 `http://localhost:3000` 即可使用。

## 📋 11 项核心筛查规则一览

1. **① 血压**：收缩压 ≥ 180mmHg 或 舒张压 ≥ 110mmHg
2. **② 血糖**：血糖 ≤ 3.9mmol/L 或 ≥ 16.7mmol/L
3. **③ 肝功能**：总胆红素 > 34.2μmol/L；ALT ＞ 80U/L；AST ＞ 80U/L
4. **④ 血脂分层**：
   - 普通人：TG ≥ 5.6 或 TC ≥ 7.2 或 LDL ≥ 4.9 mmol/L
   - 高血压患者：TG ≥ 5.2 或 LDL ＞ 3.4 mmol/L
   - 高血压+糖尿病双患人群：LDL ≥ 1.8 mmol/L
5. **⑤ 心血管危急**：胸痛胸闷心悸等症状 + 心电图异常（陈旧心梗/病理Q波/ST-T改变/快速房颤/三度房室阻滞等）
6. **⑥ 肾功能**：血清肌酐 ≥ 124μmol/L；血尿素氮 ＞ 9mmol/L
7. **⑦ 血常规**：血红蛋白 ＜ 90g/L；白细胞 ＞ 10 或 ＜ 4×10^9/L；血小板 ＜ 50 或 ＞ 300×10^9/L
8. **⑧ 尿常规**：尿蛋白 ≥ 1+；尿红细胞 ≥ 1+；尿潜血 ≥ 1+；尿蛋白和尿酮体同时 ≥ 1+
9. **⑨ 腹部B超**：超声所见提示重度脂肪肝；肝囊肿 ≥ 5cm；肾囊肿 ≥ 5cm；胆囊息肉 ≥ 1.0cm；占位性病变
10. **⑩ 胸部DR**：胸片/DR 提示占位性病变或肺部肿块
11. **⑪ 尿酸**：血尿酸 ≥ 420μmol/L

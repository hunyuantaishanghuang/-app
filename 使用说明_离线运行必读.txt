================================================================================
           老年人健康管理体检表阳性体征筛查系统 - 完全离线使用指南
================================================================================

本系统专为解决基层医疗卫生机构及公卫科电脑“无Python环境”、“不能连外网”、“跨多表多检查项目”等痛点设计。
已包含 11 项阳性体征国家标准自动判定规则，并支持一键导出【姓名+异常项清单.xlsx】。

--------------------------------------------------------------------------------
【推荐使用方式】：

方式一：最省心（零安装、零配置、无网完全可用）
  - 直接在文件夹内双击打开文件：
    👉【 双击直接离线使用_免安装版.html 】
  - 任何电脑（Windows、Mac）、任何浏览器（Edge、Chrome、360极速等）直接秒开！
  - 核心功能：
    1. 可直接把公卫导出的 Excel 表格（如超声所见表、生化检查表、血常规表等）同时拖入窗口；
    2. 系统会自动按【身份证号】跨表全外连接（Outer Join）关联全部指标；
    3. 自动高亮标出 11 项异常指标；
    4. 点击右上角【导出【姓名+异常项】清单】，瞬间生成专供上报和随访的 Excel 结果文件！

方式二：Windows 快捷运行
  - 直接双击运行：
    👉【 一键启动_Windows.bat 】
  - 会智能检测本地环境，有 Node.js 则启动全功能服务，无环境则自动拉起免安装离线版。

方式三：Python 批量命令行筛查（给有 Python 的电脑使用）
  - 打开终端或 CMD，运行：
    pip install pandas openpyxl
    python screen_elderly_health.py 表格1.xlsx 表格2.xlsx
  - 脚本将自动输出《老年人阳性体征_姓名与异常项清单.xlsx》。

方式四：Node.js 完整项目运行
  - 在当前文件夹下执行：
    npm install
    npm run dev
  - 浏览器访问 http://localhost:3000 即可。

【11项老年人阳性体征核心筛查规则】：
① 血压危象：收缩压 ≥ 180mmHg 或 舒张压 ≥ 110mmHg
② 血糖危急值：空腹血糖 ≤ 3.9mmol/L 或 ≥ 16.7mmol/L
③ 肝功能：总胆红素 > 34.2μmol/L；ALT ＞ 80U/L；AST ＞ 80U/L 中任意一项
④ 血脂分层：
   - 常规：甘油三酯 ≥ 5.6 或 总胆固醇 ≥ 7.2 或 低密度脂蛋白 ≥ 4.9 mmol/L
   - 高血压患者：甘油三酯 ≥ 5.2 或 低密度脂蛋白 ＞ 3.4 mmol/L
   - 高血压+糖尿病双患人群：低密度脂蛋白 ≥ 1.8 mmol/L
⑤ 心血管危急：胸痛胸闷心悸等症状 + 心电图异常（陈旧心梗/病理Q波/ST-T改变/快速房颤/三度房室传导阻滞等）
⑥ 肾功能：血清肌酐 ≥ 124μmol/L；血尿素氮 ＞ 9mmol/L
⑦ 血常规：血红蛋白 ＜ 90g/L；白细胞 ＞ 10 或 ＜ 4×10^9/L；血小板 ＜ 50 或 ＞ 300×10^9/L
⑧ 尿常规：尿蛋白 ≥ 1+；尿红细胞 ≥ 1+；尿潜血 ≥ 1+；尿蛋白和尿酮体同时 ≥ 1+
⑨ 腹部B超：重度脂肪肝；肝囊肿 ≥ 5cm；肾囊肿 ≥ 5cm；胆囊息肉 ≥ 1.0cm；占位性病变
⑩ 胸部DR：占位性病变或疑似肿块
⑪ 尿酸：血尿酸 ≥ 420μmol/L
